# บันทึกการเปลี่ยนแปลง

รูปแบบอ้างอิงตาม [Keep a Changelog](https://keepachangelog.com/th/1.1.0/)
และเลขเวอร์ชันตาม [Semantic Versioning](https://semver.org/lang/th/)

## [1.0.0] - 2026-09-03

รุ่นแรกที่เผยแพร่

### เพิ่มเข้ามา

- คลาส `MassmoreMAX3010x` ควบคุมชิป MAX30102, MAX30101 และ MAX30105
  โดยเขียนขึ้นจาก datasheet โดยตรง ไม่พึ่งไลบรารีอื่นนอกจาก `Wire`
- เดารุ่นชิปให้อัตโนมัติจากไดรเวอร์ LED ช่องที่ 3 และรีจิสเตอร์ proximity
- ตั้งค่าได้ครบทุกหัวข้อของชิป โหมดการทำงาน การเฉลี่ยตัวอย่าง ช่วง ADC
  อัตราสุ่ม ความกว้างพัลส์ กระแส LED ทุกดวง และช่องเวลาของโหมด multi-LED
- อ่าน FIFO แบบต่อเนื่องผ่านบัฟเฟอร์วงแหวนภายใน ไม่บล็อกการทำงาน
- อินเทอร์รัปต์ครบทุกชนิด A_FULL, PPG_RDY, ALC_OVF, PROX, DIE_TEMP_RDY
- วัดอุณหภูมิแกนชิปได้ทั้งแบบบล็อกและไม่บล็อก
- `verifyChip()` ตรวจว่าเป็นชิปแท้จากโรงงาน 11 ข้อ
- `readConfiguration()` อ่านการตั้งค่าทั้งหมดกลับมาจากชิปจริง
- อัลกอริทึม `MassmoreMAX3010xBeatDetector` จับจังหวะการเต้นของหัวใจ
- อัลกอริทึม `MassmoreMAX3010xSpO2` คำนวณออกซิเจนในเลือดด้วย ratio-of-ratios
  พร้อมให้แก้สัมประสิทธิ์เส้นโค้งสอบเทียบได้เอง
- ตัวอย่างการใช้งาน 12 ชุด ตั้งแต่ระดับพื้นฐานถึงขั้นสูง
- ชุดทดสอบโรงงานพร้อมเฟิร์มแวร์ `.bin` สำหรับ ESP32
- ชุดทดสอบ 149 ข้อ ที่คอมไพล์และรันบนเครื่อง PC ได้โดยไม่ต้องมีบอร์ด
  พร้อมตัวจำลองชิป MAX30102 ที่ทำตามพฤติกรรมใน datasheet

### จุดที่ระวังเป็นพิเศษ

- แยกกรณี FIFO เต็มพอดี 32 ตัวอย่างออกจากกรณี FIFO ว่างได้ถูกต้อง
  ซึ่งตัวชี้อ่านกับเขียนชี้ที่เดียวกันทั้งสองกรณี ถ้าไม่แยกจะทำให้ข้อมูล
  หายไปทั้งชุดเมื่อ loop() ทำงานช้ากว่าปกติ
- ไม่เดาโหมดเป็น SPO2 เมื่อชิปยังไม่ได้ถูกตั้งโหมด (ค่า MODE 0 หลังรีเซ็ต)
  เพื่อไม่ให้แกะข้อมูล FIFO ผิดความยาว
- เก็บเวลาแยกรายตัวอย่าง ผู้ใช้จึงทยอยอ่านข้ามหลายรอบของ loop() ได้
  โดยเวลาที่ติดมากับแต่ละตัวอย่างยังถูกต้อง

### ยังไม่รองรับ

- MAX30100 ซึ่งใช้ตารางรีจิสเตอร์คนละชุดกันโดยสิ้นเชิง
  ไลบรารีจะแจ้ง `MASSMORE_MAX3010X_ERR_WRONG_CHIP` ให้ทราบตั้งแต่ `begin()`
